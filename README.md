# Statusworks

Statusworks lets modpack authors and mods define custom statuses with stacks, pools, entity marks, and cooldowns on players and mobs, through CraftTweaker or a Java API. It adds no effects of its own.

Minecraft 1.12.2, Forge. Runs on Cleanroom.

This repository is in initial development. Documentation is written with the first release.

## Building

Gradle wrapper, Java 25 for the build, Java 8 bytecode output:

```text
./gradlew build
```
